# Runtime context is static per-invocation configuration

Declare a `context_schema` (e.g. a dataclass) and pass `context=` at invoke time. Context carries things like user ID, role, DB connections or API keys: data that should not be generated by the model and is not part of the conversation. It is read-only during the run and is available to tools and middleware via the runtime.

```python
from dataclasses import dataclass
from langchain.agents import create_agent

@dataclass
class Context:
    user_name: str

agent = create_agent(model="gpt-5-nano", tools=[], context_schema=Context)
agent.invoke({"messages": [{"role": "user", "content": "What's my name?"}]},
             context=Context(user_name="John Smith"))
```
